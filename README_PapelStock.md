## Descripción
PapelStock permite registrar artículos, registrar ventas con descuento automático de stock y alertar cuando un artículo alcanza su stock mínimo. Actores: vendedor y administrador.

## Trazabilidad Requisito → Caso de Uso → Pantalla

| Requisito | Caso de Uso | Pantalla Figma | Commit |
|---|---|---|---|
| RF-01 Registrar artículo | Registrar artículo | Pantalla 1: formulario de nuevo artículo | feat: SRS y README inicial (RF-01) |
| RF-02 Registrar venta | Registrar venta | Pantalla 2: selector de artículo + cantidad | docs: diagrama de casos de uso (RF-01 a RF-03) |
| RF-03 Alertar stock mínimo | Consultar stock / Alerta automática | Pantalla 3: vista con alerta de stock mínimo | feat: prototipo Figma 3 pantallas |
